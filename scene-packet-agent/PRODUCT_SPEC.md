# Scene Packet Agent — MVP

**Core promise:** Turn the movie in your head into production-ready AI video scenes.

## Workflow
New Project -> Brain Dump -> Brand -> Characters -> Scenes -> References -> Start/End Images -> Dialogue -> Independent Scene Prompts -> Dashboard -> Word/PDF/JSON/ZIP.

## Core rule
Every scene is standalone and repeats all context required to generate it.

## Future
Multiple provider adapters, direct generation, white-label installations, SaaS, embeddable/API integrations, reusable character and brand libraries.
