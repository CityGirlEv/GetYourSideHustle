# My Plan, Not My Mood — Storefront & Platform

Official Web Platform & Storefront for **My Plan, Not My Mood** ([https://nonnegotiation.com](https://nonnegotiation.com)).

## Quickstart

```bash
# Install dependencies
bun install

# Start local dev server (port 3001)
bun run dev

# Run unit test suite
bun run test

# Production build
bun run build
```

## Environment & URLs
- **Local Dev Server**: [http://localhost:3001](http://localhost:3001)
- **Production Domain**: [https://nonnegotiation.com](https://nonnegotiation.com)
